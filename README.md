# Агентная разработка — подготовка рабочего места

Интерактивная инструкция для участников программы: проверка окружения, материалы,
подключение агента к шлюзу, сборка `.env`, промпт первого прогона, чек-лист.
Страница зашифрована (AES-256-GCM, ключ из пароля через PBKDF2); пароль вводится
в браузере и никуда не отправляется. Исходник — `src/index.html`, сборка — `build.py`.

Открыть: https://wybaeb.github.io/agentic-dev-launcher/
