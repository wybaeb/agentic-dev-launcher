Агентная разработка · подготовка рабочего местаСемь шагов: от проверки окружения до первого прогона. Всё, что вы вводите, остаётся в браузере и никуда не отправляется.

1Проверьте окружение

В контейнере разработчика должны быть git, Python 3.10+ и один из агентов. Запустите:

git --version && python3 --version && (command -v claude || command -v codex || command -v opencode)

Если агент не найден — он ставится по вашей внутренней инструкции; программа не привязана к конкретному инструменту.

2Заберите материалы

git clone https://github.com/wybaeb/agentic-dev-course.git
cd agentic-dev-course && ./tools/bootstrap.sh
cd lesson-01/demo-project && python3 -m pytest -q

Восемь зелёных тестов — точка старта занятия 1.

3Подключите агента к шлюзу

Агент ходит к моделям через корпоративный шлюз. Заполните поля — ниже соберутся переменные окружения для вашего инструмента.

Переменные кладутся в .env проекта или в профиль контейнера — как принято у вас. Файл .env в репозитории уже в .gitignore.

4Соберите .env

Тот же набор одним файлом. Значения подставляются из шага 3; секрет вы вводите сами.

5Промпт для первого прогона

Шаблон постановки, с которой агент начинает с плана, а не с кода. Подставьте задачу — получите текст.

6Первый прогон — чек-лист

Агент прочитал файл правил и предъявил план до кода
Тесты на критерии приёмки появились раньше реализации
Ни один существующий тест не ослаблен и не удалён
Работа в отдельной ветке, отчёт совпадает с дифом
Расход за прогон известен — записан рядом с результатом

7Домашнее задание

Одна своя рабочая задача через полный цикл с агентом. Запись — по шаблону lesson-01/runs/TEMPLATE.md: шаг, что сделал агент, где вмешались и почему. Разбор — через неделю.
